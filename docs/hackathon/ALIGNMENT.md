## Track and scoped problem

Selected proposal alignment: **Track 4 — Knowledge and verification tools empowering those introducing Islam** (أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام). See guide page 11. Basirah supports editors by checking quotation fidelity and whether the cited evidence supports a specific conclusion. It is not a broad religious chatbot.

## Source restrictions and practical consequences

The reference package recommends named sources and source categories, including Quran resources, approved tafsir references and authenticated hadith collections with further verification where appropriate. Select works deliberately with the content reviewer. A technically accessible API is not automatically an approved corpus. Preserve scholar/source attribution and distinguish generated explanation from quotation.
